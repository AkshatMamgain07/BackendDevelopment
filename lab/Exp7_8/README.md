# Lab Experiments 7 and 8 – JavaScript ES6 To-Do App

## Aim
Build a simple to-do list using JavaScript ES6 features and DOM event handling.

## Files
- `index.html` — page structure and styling for the to-do list.
- `app.js` — task model, rendering, and add, complete, and delete behavior.

## How to Run
1. Download or clone the repository.
2. Open `index.html` in a modern web browser. No server or package installation is required.
3. Enter a task and select **Add** or press **Enter**.
4. Select a task to toggle its completed state. Select **Delete** to remove it.

## Concepts Demonstrated
- ES6 classes and `let`
- Arrow functions, destructuring, and the spread operator
- Array methods (`forEach`, `filter`, and `map`)
- DOM creation and event delegation
- Keyboard and click event listeners

## Note
Tasks are held in memory and reset when the page is refreshed.
