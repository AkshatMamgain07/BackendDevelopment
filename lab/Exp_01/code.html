About HTML5

HTML5 introduces semantic elements like <header>, <nav>, <main>, <section>, <article>, <aside>, and <footer>, unlike HTML4 which relied mostly on generic <div> tags.

Note: Semantic tags improve accessibility and SEO because search engines and screen readers understand page structure better.

"HTML5 defines a clear, predictable structure for web documents."
