Lab Experiments 7 and 8

Aim: Build a simple to-do list using JavaScript ES6 features and DOM event handling.

Requirements

  • A modern web browser and a text editor
  • The experiment files: todo.html and app.js
  • No package installation or Node.js is required

Run Locally

  1. Download or clone the repository and open the lab/Exp7_8 folder.
  2. Open todo.html in a modern browser. No server is required.
  3. Alternatively, run python -m http.server 8000 from that folder and visit http://localhost:8000/todo.html.

Procedure / Steps to Perform

  1. Open the app and confirm the input, Add button, and empty task list appear.
  2. Inspect the Task class in app.js; it creates a task with an ID, title, and completion state.
  3. Enter a task and select Add or press Enter. Confirm it appears.
  4. Select the task text to toggle completion and confirm completed text is crossed out.
  5. Select Delete to remove a task. Try this with several tasks.
  6. Refresh the page and observe that tasks reset because they are stored in memory.

Open the To-Do App

Try adding tasks, marking them complete, and deleting them.

Launch the To-Do App

Concepts Demonstrated

  • ES6 classes and let
  • Arrow functions, destructuring, and the spread operator
  • Array methods: forEach, filter, and map
  • DOM creation, event delegation, and click and keyboard listeners

Note: Tasks are stored in memory and reset when the page is refreshed.
