Experiment 12(A): Express.js Routes and EJS

Aim: Demonstrate Express response types, route and query parameters, POST requests, and server-rendered EJS templates.

Requirements

  • Node.js and npm
  • A modern browser, terminal, and text editor
  • Project packages installed with npm install

Run Locally

  1. Open a terminal in the lab/Exp12_A folder.
  2. Run npm install.
  3. Run npm start.
  4. Visit http://localhost:3000. Keep the server running in the terminal.

Steps to Perform

  1. Open /text, /html, and /json to compare response types.
  2. Try route parameters at /user/42 and /product/books/7.
  3. Try query parameters at /search?q=express&page=1&limit=5.
  4. Try the calculator at /calculate?num1=8&num2=2&operation=multiply.
  5. View EJS pages at /home, /users, and /profile/42.
  6. Use Postman or another REST client to send POST requests to /user, /register, and /login.

Why this page is here: GitHub Pages hosts static files and cannot run a Node.js/Express server. Use the local steps above to run and interact with this experiment.
